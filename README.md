# Student Grade Calculator

A simple **Student Grade Calculator** developed using Java that calculates total marks, average percentage, and assigns grades based on student performance. This project demonstrates Java basics, loops, conditional statements, and user input handling.

## Features

* Enter student details
* Add marks for multiple subjects
* Calculate total marks
* Calculate average percentage
* Automatically assign grades
* Validate marks input
* Display student result summary

## Technologies Used

* Java
* Scanner Class
* Conditional Statements
* Loops
* Basic Mathematical Calculations
